Chatbot Project
Overview
This is a simple chatbot that uses keyword recognition and predefined responses to interact with users. The chatbot can respond to various types of user messages, such as greetings, farewells, and music recommendations. The bot uses a function to check for certain keywords in the user's message and returns the most relevant response.

Features
Keyword Recognition: The bot identifies keywords from the user's input and matches them to predefined responses.

Custom Responses: It can respond to greetings, farewells, and specific requests like music recommendations.

Response Ranking: The bot calculates the relevance of each response based on the user's message and returns the best match.

Simple Interface: The bot continuously runs and interacts with the user until the user ends the conversation.

Requirements
Python 3.x
